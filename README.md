# DoTT Connect – Premium V3

Premium event/kiosk redesign with glass UI, AURA status, language cards, circular timer, editor-style code panel, review screen, celebratory result state, fixed full-screen layout, and the same working AURA generation/fallback logic.

Run:

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

Open `http://localhost:8501` and use F11 for the stall display.
